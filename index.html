基于大语言模型的上市公司年报信息处理LLM-powered processing of listed-company annual reports

独立开发Independent

沪深 A 股 2012–2025 年的年报文本超过一千万句。我用一套 prompt 流程让大模型对这批语料做信息抽取、分类与多源匹配，再用 Python 把整个链条串起来，让它能重复跑、能校验、能导出。The annual reports of Shanghai- and Shenzhen-listed companies from 2012 to 2025 run past ten million sentences. I built a prompt pipeline that has a large language model extract, classify and cross-match this corpus, and wired the whole chain together in Python so it can be re-run, checked and exported.

02抽取与分类Extract and classifyprompt 流程逐轮迭代，按目标标签抽取Iterated prompts pull out the target labels
03抽样复核Sample and verify人工抽样检查，误差回流改进 promptManual sampling; errors feed back into the prompts
04结构化导出Export校验结果写入 Excel，可直接进分析Verified output written to Excel, ready for analysis
  • 原本需要数周的人工处理，现在是一条可复用的自动化流水线。A process that used to take weeks of manual work is now a reusable automated pipeline.
  • 全量运行把每条记录的状态写进 SQLite，中断后从断点接着跑；并发从 3 起步，按限流压力与吞吐逐级升到 15。Full runs keep per-item state in SQLite so an interrupted run resumes where it stopped; concurrency starts at 3 and steps up to 15 as throughput allows.
  • 两阶段标注：先用低成本模型做粗筛，再让强模型复核候选句，成本压下来而判定口径不放宽。Two-stage labelling: a cheaper model screens first, a stronger model reviews the sentences that survive — cost down without loosening the standard.
  • 全程可追溯：每一条输出都能回到原始句子。Every output traces back to the sentence it came from.
